Pause Notifications (Focus Mode)

This does exactly what clicking your Slack profile photo → "Pause notifications" does — Slack always needs a fixed duration for this, so treat it as a ceiling, not the actual session length. Ending focus mode calls "Resume notifications" immediately, regardless of how much of this time is left.
