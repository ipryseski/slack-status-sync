Pause Notifications (Focus Mode)

This does exactly what clicking your Slack profile photo → "Pause notifications" does. Slack always needs a fixed duration, but the plugin reads the real length from the focus session itself, so this fallback only applies when the session doesn't report one (for example Flowtime mode, or the "Simulate focus start" button below). Ending focus mode calls "Resume notifications" immediately either way.

While a focus session is running this status takes precedence over task tracking, so starting or switching tasks won't overwrite it. When the session ends, your tracking status is restored automatically.
